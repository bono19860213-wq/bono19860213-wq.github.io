ホーム プライバシーポリシー 利用規約

プライバシーポリシー

制定日：2026年10月11日

このポリシーは、宍舞ぼの YouTube運営システム（以下「本アプリ」）がGoogleアカウントとYouTubeのデータをどのように取得・利用・保存・共有・削除するかを説明するものです。本アプリは、運営者である宍舞ぼのが自分のYouTubeチャンネルを分析するためだけに使う本人専用のツールで、運営者本人以外の利用者はいません。

1. YouTube API Services の利用

本アプリは YouTube API Services を利用しています。利用者はYouTube利用規約に従うものとします。Googleによるデータの取り扱いについてはGoogleプライバシーポリシーをご覧ください。

2. 取得するデータ

種類内容取得方法
自分のチャンネルの分析データ再生数、総再生時間、平均視聴時間、平均視聴率、登録者の増減、高評価数、コメント数（件数のみ）、形式別（通常動画・ショート・ライブ）の集計、流入経路別の再生数、チャンネルの登録者数などの統計運営者本人のログイン（YouTube Analytics API・YouTube Data API）
自分のチャンネルの動画情報動画のタイトル、公開日時、長さ、ライブ配信の開始・終了日時、累計の再生数・高評価数・コメント数運営者本人のログイン（YouTube Data API）
自分の動画の字幕運営者本人の動画の字幕テキスト（自動字幕を含む）。運営者が指定した動画だけ運営者本人のログイン（YouTube Data API）
認証情報Googleのログインで発行されるアクセストークン・更新トークンGoogleのOAuth 2.0
他チャンネルの公開情報比較のために運営者が指定した他チャンネルの、チャンネル名・チャンネルID、登録者数、動画数、動画のタイトル・公開日時・長さ・概要欄、再生数・高評価数・コメント数（件数のみ）APIキー（ログインなし。誰でも見られる公開情報のみ）

次のデータはAPIで取得しません：視聴者の個人情報、コメントの本文、メールアドレス・連絡先、収益に関するデータ、Gmail・Googleドライブなど他のGoogleサービスの中身。

なお、字幕には配信中に読み上げた視聴者の呼び名などが含まれる場合があります。字幕は分析のためだけに使い、呼び名などの個人を示す情報はレポートやメモに書き写しません（字幕自体も取得から14日で削除します）。

このほか、運営者がYouTube Studioから手動で書き出した数値（インプレッション数・クリック率）を取り込むことがあります。これはAPIを通じて取得するものではありません。

3. 利用目的

取得したデータは、運営者本人のチャンネルの分析（週ごとの集計・比較レポートの作成）、配信・動画の企画づくり、ショート動画にする場面の候補探しにだけ使います。広告配信、データの販売、信用評価など、この目的以外には使いません。

4. 保存場所と保存方法

  • 取得したデータは、運営者本人のパソコンの中にファイルとして保存します。本アプリ用の外部サーバーはありません。
  • 認証情報（トークン）は、運営者のパソコンの中の専用フォルダに保存し、公開・共有・外部への送信はしません。Googleへの通信は暗号化（HTTPS）して行います。
  • 変更の記録のため、運営者のパソコンの中だけで動くバージョン管理（Git）を使っています。インターネット上の共有サービスには送りません。変更履歴に残ったデータも、下の保存期間のルールに沿って整理します。
  • ファイルを更新するときは、更新前の版をバックアップとして同じパソコンの中に残します（保存期間は6.のとおり）。
  • 作業を手伝うAIツール（Claude Code）の会話・作業の記録が、運営者のパソコンの中に残ります。パソコン内の記録がどれだけ残るかは、ツールの設定によって決まります（現在は初期設定のまま使っています）。提供元のサーバー側での保存については、5.の「外部サービス側に残るデータ」をご覧ください。

5. 第三者への提供・外部サービスでの処理

データを販売することはありません。運営者本人の分析作業のため、次の外部サービスでデータを扱います。どれも運営者本人のアカウントで利用しています。

サービス扱うデータ目的
Googleドライブ（運営者本人のアカウント）分析レポート・企画メモ（YouTubeの数値と動画タイトルを含む）。生データ・字幕・字幕の引用を含むメモ・他チャンネルのデータ・認証情報は保存しない（現在は同期を停止中。6-2.参照）運営者本人がレポートを保管・閲覧するため
Anthropic社のClaude（Claude Code）分析データ、動画情報、字幕、他チャンネルの公開情報。認証情報の中身は扱わない集計結果の分析、レポート・企画案の作成
OpenAI社のChatGPT運営者本人が手動で貼り付ける分析レポート（YouTubeの数値と動画タイトルを含む）企画・タイトル・告知文の検討

上記以外の第三者には、法令にもとづく場合を除き、提供しません。

外部サービス側に残るデータ

  • Claude Code・ChatGPTで扱った内容は、それぞれの提供元（Anthropic社・OpenAI社）のサーバーで処理され、各社の保存方針と運営者のアカウント設定に従って保存される場合があります（Anthropic社のプライバシーポリシー／OpenAI社のプライバシーポリシー）。
  • 運営者のパソコンの中のファイルを削除しても、これらのサービス側に保存されたデータは削除されません。ChatGPTの会話は、運営者本人がChatGPT上で削除します。サービス側でどこまで削除されるかは、各社の方針によります。
  • Googleドライブにコピーしたファイルは、ドライブ上で（ゴミ箱を含めて）削除します。

6. 保存期間のルール

保存期間の管理には専用のツールを使います。ツールが期限を確認して削除対象の一覧を出し、運営者本人が内容を確認・承認してから削除します（期限が来ても自動では削除しません）。動画情報やタイトルの更新は、週1回の作業の中でツールが行います。

  • 自分のチャンネルの分析データ（統計）：分析に必要な期間保存します。保存を続ける間は、少なくとも30日に1回、Googleの認証が有効であることと、動画がYouTube上で削除されていないことを確認します。YouTube上で削除された動画のデータは削除します。
  • 自分のチャンネルの動画情報（タイトル・公開日など）：少なくとも週に1回、最新の情報に更新します。
  • 自分の動画の字幕、他チャンネルの公開情報、データのバックアップ：取得から14日を過ぎると削除の対象になり、期限チェックの結果を運営者が確認・承認して削除します。削除は、遅くとも取得から30日以内に行います。
  • 分析レポート・Shorts候補などの文書：動画タイトルは少なくとも週に1回、最新の情報に更新します。更新できない状態が続いた場合は、古いタイトルを残さず消します。字幕からの引用や他チャンネルの数値は、上記の期限内に文書から削除します。
  • 変更履歴（Git）に残ったデータも、同じ期限で整理します。
  • 認証が確認できない状態が続いた場合は、最後に確認できた日から30日以内に、YouTube APIを通じて取得した保存データを削除します。

7. アクセスの取り消しとデータの削除

  • 本アプリへのアクセス許可は、Googleのセキュリティ設定ページでいつでも取り消せます。
  • 本アプリ側で取り消す場合は、Googleにトークンの無効化を依頼したうえで、保存しているトークンを削除します。
  • アクセスを取り消した場合や削除の依頼があった場合、YouTube APIを通じて取得した保存データを、運営者が確認したうえで7日以内に削除します。Googleドライブ・ChatGPTなど外部サービス上のデータも、同じ期間内に運営者本人がそれぞれのサービス上で削除します（サービス側でどこまで削除されるかは、各社の方針によります）。
  • 本アプリで保存データを削除しても、YouTube上の動画やデータには影響しません。YouTube上のデータを削除するには、YouTubeのサービス上で操作する必要があります。

8. Cookieについて

本アプリ（運営者のパソコンで動くプログラム）と、このWebサイトは、Cookieや閲覧解析ツールを使いません。ただし、このWebサイトを公開しているGitHub Pagesでは、GitHub社がアクセス記録を取得する場合があります（GitHub一般プライバシーステートメント）。
